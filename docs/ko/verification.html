최신 검증 기록과 한계

최신 결과 JSON에 현재 배포물의 검증 시각·대상·결과를 기록합니다. 공개 저장소에는 이 검증 파일 하나만 유지합니다. 이전 검증·이관·임시 증빙 파일은 Git 이력에 남아 있으며 현재 배포 묶음에는 포함하지 않습니다.

확인 범위

대상 확인할 내용
원본 데이터 정책 8개·사례 100건과 train 56 / validation 12 / dev 12 / test 20 유지
가이드 docs/의 영어·한국어 전체 가이드, 영어 기본 진입 연결, 언어 전환, CLI 문법·명령 해설과 상대 링크
포털 사진 실제 화면 14장, 출처·가림·치수·해시, 이미지 표시와 확대 링크
웹·인쇄 데스크톱·모바일, 밝은/어두운 화면, 언어별 UI, 인쇄 목차와 링크
PDF 영어·한국어 텍스트·필수 내용·빈 페이지·잘림·로컬 머신 링크·사진 포함
패키지 최신 파일과 검증 하나만 포함, 비공개 환경·인증·원본 실행 자료 제외

검증 JSON의 status: PASS는 그 파일에 명시한 로컬 문서·패키지 검사가 통과했다는 뜻입니다. Azure 실행 성공, 에이전트 품질 합격이나 사람의 운영 승인을 뜻하지 않습니다. GitHub Pages는 생성된 정적 가이드를 제공하며 CLI나 모델을 실행하지 않습니다.

LIVE 결과와 구분하기

마지막으로 보고된 2026-09-30 LIVE 품질 판정은 HOLD입니다. 교정 불일치·중요 실패가 남았고, 최종 fresh 시험은 차단되었으며 사람의 운영 승인은 없었습니다. 현재 검색 Judge 1.1.0을 포함한 평가 정의·게이트·실습 데이터는 그대로 유지합니다.

이번 문서 번역·게시에서는 유료 모델·평가·최적화·학습을 다시 실행하지 않았습니다. 이전 점수나 작업 ID를 새로운 실행 결과로 바꾸지 않으며, 최신 문서 검증으로 기존 HOLD를 해소한 것으로 보지 않습니다.

실제 포털 사진은 기존 환경을 Headless Playwright로 촬영한 자료입니다. 촬영 기록의 출처와 상태를 확인합니다. 미제출 설정 화면, 기존 서비스 결과, 현재 참가자의 실행 결과는 서로 다릅니다.

보존 기준

  • 현재 실행 코드·정책·데이터·평가기·14개 포털 사진과 docs/의 최신 HTML/PDF를 유지합니다.
  • 비공개 .lab/의 원본 실행·승인·소유 기록은 저장소 정리 대상이 아닙니다.
  • Azure 자원·권한은 변경하거나 삭제하지 않습니다. 호스팅·로그 비용도 자동으로 멈추지 않습니다.
  • 새 검증 결과를 게시할 때는 evidence/latest.json을 갱신하고 이전 날짜별 파일을 추가하지 않습니다.

출처

Contoso Atlas Cloud와 정책·사례는 이 실습을 위한 합성 자료이며 실제 공급자의 약관이나 실제 고객 자료가 아닙니다.

이전 실습 설계 참고 원본은 foundry-evaluation-labs-v0.9의 고정 커밋입니다. 해당 보관 저장소는 별도 접근 권한이 필요할 수 있습니다. 상세 이관 기록은 이 저장소의 Git 이력에 보존하며, 공개 열람 자체가 참고 원본의 추가 사용 허락을 부여하지는 않습니다.

Microsoft 공식 Foundry 아이콘과 포털 사진의 출처·사용 범위는 NOTICE에 있습니다. 공식 아이콘의 원본 바이트와 사용 조건을 유지합니다.

로컬 재검증

python -m lab validate
python scripts/build_guide.py
python scripts/build_guide.py --check
python -m unittest discover -s tests -q

명령 해설: 순서대로 원본 데이터 검사, HTML 생성, 쓰기 없는 최신 상태 확인, 로컬 자동 검사입니다. Azure를 호출하지 않습니다. PDF와 ZIP은 별도로 재생성·검사한 뒤 해당 결과만 최신 JSON에 기록합니다.
