실제 포털 실습 녹화 v1.1

새 리소스 그룹 → 정책 검색 Agent → 기준선 평가 → Instruction 최적화 → 검토한 지침 v2 재평가. 터미널 없이 실제 포털에서 진행했습니다. 음성 내레이션은 없으며 한국어 고정 자막이 영상 하단에 포함되어 있습니다.

실측 통과율: Relevance 64% → 100%, TaskAdherence 73% → 100%. 공통 유효 11문항의 결과입니다. 같은 1문항은 제공자 차단되어 두 run 모두 Partial이며, TaskAdherence의 통계 판정은 Inconclusive입니다.

선택형 자막 파일을 불러오지 못했습니다. 영상의 고정 자막은 그대로 볼 수 있습니다. file://에서 열었다면 http(s) 페이지나 MP4 플레이어를 사용하세요.
